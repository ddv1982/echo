## Durable acceleration decisions

Plan 17 replaced host qualification with an explicit user choice. CPU is the
default. A user who selects GPU downloads `WhisperVulkanRuntime` on demand.
The application package does not contain that runtime.

Echo identifies a selected Vulkan device by its device UUID and driver UUID.
If the pinned device is absent, Echo uses CPU and reports the reason. It does
not choose a different GPU. An accelerated run must produce a matching Vulkan
receipt. A failed or mismatched run quarantines that device and retries once on
CPU.

The retained tuning uses beam size 3, best-of 5, and temperature fallback. The
archived `whisper-phase5-small-v192-b3/decision.md` records 400 transcriptions
with no WER delta across five languages and a 57.8 percent paired median time
reduction. That measurement covered one Intel Iris Xe host. It is evidence for
the selected tuning, not a claim about every Vulkan device.

The GPU runtime remains an operator-built artifact under its own release tag.
`crates/echo/src/install/catalog.rs` pins its URL, size, archive digest, and
installed-file inventory. Application releases use the packages built by CI
and no longer substitute host-qualified draft assets.

The benchmark, corpus, runtime build, runtime verification, acceleration-mode,
admission sweep, promotion, and composition tools remain available for
maintained research. The archived commands only verified removed product
contracts or the fixed PR 16 evidence bundle.
