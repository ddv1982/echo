# Large Turbo architecture arena synthesis

## Rubric

The candidates were scored on exact fail-closed selection, complete package verification, honest Intel shared-memory evidence, interface depth, and incremental release verification.

## Candidates

- Candidate A did not produce its files within the arena window and was recorded as a dropout.
- Candidate B proposed one strict admission set, shared runtime artifacts, per-identity cache seeds, and telemetry in the existing product measurement path.
- Candidate C proposed an atomic record array with the most explicit extracted-package inventory.
- Candidate D proposed a separate screen command, a package composer, and a temporary legacy read path.

## Pick

Candidate B is the base. The independent judge scored it highest on every criterion. It has the smallest product caller surface, the clearest three-valued resource claim, and the strongest refusal to mix legacy and new package reads.

The lead agreed with the judge. Candidate B best preserves the rule that one installed package is one complete trust boundary.

## Grafts

Candidate C contributed the complete extracted-resource inventory. The synthesized design records every owned file and symlink and rejects missing, extra, changed, or escaping entries.

Candidate D contributed one useful implementation separation. The Linux process sampler lives in a small imported module because `benchmark-stt.py` is already large. The existing benchmark and sweep remain the only measurement entrypoints.

Candidate D also made the upgrade question explicit. The synthesis resolves it without a compatibility reader: the new executable hash already requires Small re-promotion, so the next qualified package moves atomically to the new schema.

## Rejections

- A separate `screen-whisper-admission.py` would duplicate orchestration and risk measuring a different path.
- A legacy runtime fallback would create two package trust rules and cannot authorize the new executable anyway.
- Model names or filenames are diagnostic labels, not admission selectors.
- Process RSS or model file size cannot be called Intel GPU memory.
- Duplicate per-model runtimes would create drift without adding capability.

## Verification

The synthesized architecture preserves the existing product call, CPU fallback, exact identity, live receipt, and identity-keyed quarantine. Its added surfaces each own one body of knowledge: Linux child evidence, package composition, or strict selection.

Verdict: `VERIFIED` as the implementation contract.
